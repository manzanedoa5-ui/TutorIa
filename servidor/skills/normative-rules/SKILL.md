# Uso en TutorIA

Consulta el catálogo y la fuente institucional vigente cuando estén disponibles. Identifica la regla, su fuente y la acción propuesta. Si faltan fuentes verificadas o el dato específico, devuelve el caso para revisión humana. El campo `cursos_repetidos` del prototipo cuenta cursos y no identifica por sí solo una tercera matrícula.

Correcto: solicitar revisión cuando solo consta el conteo de cursos repetidos. Incorrecto: aplicar una regla de tercera matrícula a partir de ese conteo.
