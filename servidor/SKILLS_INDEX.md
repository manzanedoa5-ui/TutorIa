# Skills de TutorIA

Guías de TutorIA y roles previstos para su uso.

| Skill | Rol que la consulta |
| --- | --- |
| [student-data-validation](skills/student-data-validation/SKILL.md) | Validación de datos |
| [risk-scoring](skills/risk-scoring/SKILL.md) | Evaluación del riesgo |

FastAPI ejecuta los controles deterministas de `harness.py` al calcular casos. Los archivos `SKILL.md` documentan cómo interpretar y revisar los resultados. Un asistente puede consultarlos manualmente y la demo ejecuta sus controles mediante Python, sin un agente de lenguaje.
